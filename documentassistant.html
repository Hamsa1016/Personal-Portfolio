Introduction

AI Document Intelligence Assistant is an intelligent web application designed to process uploaded documents and provide meaningful insights using AI and NLP techniques.

What This Project Does

Users can upload PDF documents, ask questions, generate summaries, and extract important information from the content automatically.

Features

  • PDF document upload
  • AI-based question answering
  • Automatic text summarization
  • Keyword extraction
  • Interactive chat interface

Tech Stack

  • Python
  • Streamlit
  • OpenAI API
  • PyPDF2
  • NLP

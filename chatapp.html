REAL-TIME CHAT APPLICATION

Chat App

A full-stack real-time chat application built using MERN stack with live messaging and user presence.

View GitHub Repository

Introduction

This project is a real-time chat application that allows users to communicate instantly. It helped me understand how frontend and backend interact continuously using WebSockets.

What This Project Does

Users can register, log in, and start chatting in real-time. The system tracks online users, shows typing indicators, and ensures smooth communication.

Features

  • Real-time messaging using Socket.IO
  • User authentication (Login/Register)
  • Online / Offline user status
  • Typing indicator
  • Message delivery & seen status

Tech Stack

  • MongoDB
  • Express.js
  • React.js
  • Node.js
  • Socket.IO

What I Learned

  • Building real-time applications
  • Using WebSockets (Socket.IO)
  • Frontend-backend communication
  • State management in React

HEALTHCARE APPLICATION

Med Access

Secure system to manage patient data with strict access control and workflow validation.

View GitHub Repository

Introduction

Med Access is a secure backend system designed for hospitals to control access to sensitive patient data. It ensures that only authorized users can perform specific actions based on roles and workflows.

What This Project Does

The system implements multi-layer security including role-based access, intent validation, and workflow rules to prevent misuse of patient data.

Features

  • JWT Authentication
  • Role-Based Access Control (Admin, Doctor, Nurse)
  • Intent-Based Access Control
  • Shift-Based Access
  • IP Restriction
  • Audit Logging

Tech Stack

  • Spring Boot
  • Spring Security
  • JWT
  • MySQL

What I Learned

  • Designing secure backend systems
  • Implementing multi-layer authentication
  • Handling real-world security scenarios

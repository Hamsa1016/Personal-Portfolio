DESKTOP APPLICATION

🌤️ Weather App

A Python-based desktop application that provides real-time weather updates using API integration.

View GitHub Repository

Introduction

This project is a desktop weather application built using Python and Tkinter. It fetches real-time weather data and displays it in a simple graphical interface.

Features

  • Detects user location automatically (IP-based)
  • Search weather by city name
  • Displays temperature, humidity, and wind speed
  • Shows weather condition with icon
  • Provides short-term forecast
  • User-friendly GUI

Tech Stack

  • Python
  • Tkinter
  • Requests
  • PIL
  • Geocoder
  • OpenWeatherMap API

How It Works

  • App detects user location using IP
  • Fetches weather data using API
  • Displays weather details in GUI
  • User can also search manually by city

API Setup

Get your API key from OpenWeatherMap and replace it in the code: 

API_KEY = "your_api_key_here"

What I Learned

  • Building GUI using Tkinter
  • Handling real-time data

WEB APPLICATION

📝 To-Do List App

A simple and interactive task management application to organize daily activities efficiently.

View GitHub Repository

Introduction

This project is a simple To-Do List web application that helps users manage their daily tasks. It provides an easy interface to add, complete, and delete tasks.

Features

  • Add new tasks
  • Mark tasks as completed
  • Delete tasks
  • Data stored using Local Storage
  • Clean and responsive UI

Tech Stack

  • HTML
  • CSS
  • JavaScript

How It Works

  • User enters a task and clicks Add
  • Task is displayed in list
  • User can mark as complete or delete
  • Data is stored in browser using Local Storage

What I Learned

  • DOM manipulation using JavaScript
  • Using Local Storage
  • Building interactive UI

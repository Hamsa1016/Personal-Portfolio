NLP APPLICATION

Text Sentiment Analyzer

A simple NLP-based web app that analyzes user input text and predicts sentiment.

View GitHub Repository

Introduction

This project is a Natural Language Processing (NLP) application that analyzes text data. It helped me understand how machine learning can be applied to real-world text analysis.

What This Project Does

Users can enter text, and the system processes it to extract keywords and determine whether the sentiment is positive, negative, or neutral.

Features

  • Text preprocessing and cleaning
  • Keyword extraction
  • Sentiment analysis (Positive / Negative / Neutral)

Tech Stack

  • Python
  • Streamlit
  • TextBlob
  • NLTK

What I Learned

  • Basics of Natural Language Processing
  • Working with text data
  • Using Python libraries like TextBlob & NLTK
  • Building simple ML-based web apps
